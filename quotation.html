1. Executive Summary & Architecture

Conversion of the static Power Diagnostics website into a high-performance, dynamic web platform. The platform features an Angular Server-Side Rendered (SSR) frontend for maximum search engine visibility (SEO), a robust .NET Web API (Clean Architecture with CQRS & MediatR), PostgreSQL database with EF Core, Azure Blob Storage for image/PDF assets, and Azure Functions for serverless email processing.

2. Scope of Modules & Deliverables

A. Angular SSR Frontend (SEO Ready)

  • Server-Side Rendering (SSR): Full pre-rendering for Google/Bing indexing.
  • Header: Search bar, Quick Connect pop-up & Enquiry Cart modal.
  • Home Page: 6-7 sliding banners, 10 featured products, services grid, category highlight cards, brands carousel, and floating WhatsApp/Social overlays.
  • Catalog Page: Left sidebar filters (by Brand & Category/Subcategory).
  • Product Details: Dynamic specifications table, multi-angle photo gallery, features, and PDF downloads.

B. Admin Management Portal

  • Admin Auth: Secure JWT authentication and role protection.
  • Brand Master: Manage brands and upload logos to Azure Blob Storage.
  • Category & Subcategory: Hierarchy, icons, and banner setup.
  • Product Master: Rich dynamic specifications builder, multi-image uploader, and downloadable PDF datasheet manager.
  • Enquiries Dashboard: Review, filter, and track customer quotation requests.

C. Backend API (.NET Clean Architecture)

  • Clean Architecture: Domain, Application, Infrastructure, and API layers.
  • CQRS & MediatR: Segregated Command and Query pipelines.
  • PostgreSQL + EF Core: Relational schema with LINQ queries & migrations.
  • Repository & Unit of Work: Clean abstracted data access.
  • Automated Testing: xUnit unit and integration test suite.

D. Serverless Email & Cloud Integrations

  • Azure Functions: Queue-triggered serverless email pipeline.
  • Customer Confirmation: Automated branded quotation receipt email.
  • Sales Team Alert: Instant lead email to internal sales inbox.
  • SEO Dynamic Engine: Dynamic Title, OpenGraph tags, sitemap.xml, robots.txt, and Schema.org JSON-LD structured data.

3. Handover & Deliverables Checklist

  • Complete Source Code: Backend (.NET Clean Architecture), Frontend (Angular SSR), and Azure Functions.
  • Database Assets: PostgreSQL EF Core migrations and initial seeding scripts.
  • Deployment Assets: Dockerfiles, CI/CD pipeline configs, and Swagger API docs.
